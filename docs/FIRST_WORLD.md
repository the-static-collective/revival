# Revival 010 — The First World

Revival 010 composes the already-proven Revival 007-009 instruments into one
deterministic, standalone, walkable Scripture world.

Its thesis is simple:

> **Every object in this world knows where it came from.**

This is a presentation/world-composition layer. Frozen kernel v1 is unchanged.

## What 010 composes

The first world binds three existing receipted instruments without merging
their authority:

- **Corpus Atlas / Dangerous Lemma Doors** — source-backed Genesis 1:1-3 and
  exact declared OSHB lemma traversal.
- **Aleph-Tav Instrument** — derived morpheme-family membership plus
  source/operator/letters/hidden projection experiments.
- **Object Relations** — pinned MACULA syntax and semantic-frame relations,
  aligned back to the OSHB witness.

The world receipt binds the child Atlas receipts, composed rooms, and projection
set.

## Build it

```bash
python -m revival.first_world \
  corpora/oshb-v2.2-genesis-opening.json \
  --macula-xml sources/macula-hebrew/Gen.1.1-lowfat.xml \
  --macula-manifest sources/macula-hebrew/source.json \
  --output /tmp/revival-first-world.html \
  --pretty
```

Open the resulting HTML file directly. It requires no server and makes no
network calls.

## Projection changes the world, not the witness

The first world exposes four projection modes over the same corpus identity:

```text
source
operator
letters
hidden
```

For the Genesis 1:1 Aleph-Tav occurrences those modes reuse the already-proven
Revival 008 projections:

```text
אֵת        source
[OBJ→]     operator
⟦את⟧      letters
∅          hidden
```

A suppressed token remains clickable as `∅`. The room still exposes the held
source token and its receipts, so disappearance is inspectable rather than
silent.

## One room, several attributable worlds

A token room may expose several layers at once:

```text
SOURCE
LEMMA
ALEPH-TAV FAMILY
SYNTAX
SEMANTIC FRAME
INTERPRETATION FOG
```

Those labels do not mean the layers are equivalent.

The current boundary is explicit:

```text
source != annotation
annotation != derivation
derivation != interpretation
syntax != semantic frame
navigation != theology
projection != witness
```

## Epistemic topology

Revival 010 turns provenance state into navigation state.

| Status | World behavior | Meaning |
| --- | --- | --- |
| source-backed | solid door | carried directly from the held source representation |
| attributed | solid door with receipt | declared by an attributable external annotation layer |
| derived | constructed door | lawfully computed from attributable inputs |
| fog | no door | this world does not promote a relation here |

The final category is important.

010 does not fill missing interpretation with an attractive guess. Symbolic,
theological, historical, or other interpretive relations can later become
walkable only when they arrive as separately attributable downstream layers.

## What is actually unified

The browser surface can now move continuously across:

```text
source-order neighbor
        ↓
exact-lemma occurrence
        ↓
Aleph-Tav family occurrence
        ↓
governing verb
        ↓
marked object phrase
        ↓
semantic A1 head
        ↓
another room
```

A traversal trail remains visible while the reader moves.

This is the first executable version of the broader Revival claim that Scripture
can become an inhabitable source-grounded world without making compelling
presentation indistinguishable from evidence.

## What 010 does not claim

Revival 010 does not establish:

- a preferred translation;
- textual-critical priority;
- lexical sense identity from lemma identity;
- theology from grammar;
- symbolism from letter order;
- historical reconstruction;
- that MACULA syntax and semantic frames are the same evidence;
- that a walkable relation is canonical because it is visually convincing.

The world is allowed to become strange.

Its ancestry must remain inspectable.
